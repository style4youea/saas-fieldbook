# SaaS Fieldbook

Practical software research for small businesses, ecommerce teams and B2B operators.

Live site: https://style4youea.github.io/saas-fieldbook/

## Editorial principles

- Separate hands-on testing from vendor/documentation research.
- Focus on real workflows, pricing, setup effort and trade-offs.
- Disclose affiliate relationships clearly.
- Re-check time-sensitive pricing and product claims before publication.

## Publishing

This site is published with GitHub Pages from the `main` branch and repository root.
